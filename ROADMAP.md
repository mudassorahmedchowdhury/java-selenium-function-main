# Release Roadmap

Plans may change; discuss via issues. Items marked 🟢 are good entry points for contributors.

## Released
- **0.2.0** – Core interactions: buttons, sidebar, forms, alerts, windows, upload, table, date, custom dropdown; JUnit 5 integration; demo module.

## 0.3.0 – Contributor-ready and hardening
- 🟢 More Javadoc examples and demo scenarios
- 🟢 Expand fixture-based `*IT` coverage
- Screenshots on failure and flaky-test guidance

## 0.4.0 – More components
- 🟢 Tabs, accordion, tooltip, breadcrumb helpers
- Drag-and-drop, iframe and shadow-DOM helpers
- Multi-browser (Firefox, Edge) CI matrix

## 0.5.0 – Reporting and developer experience
- Logging/reporting hooks (Allure-friendly)
- Locator strategy plugins
- Page-object helper utilities

## 1.0.0 – Stable API
- API freeze and deprecation policy
- Documentation site
